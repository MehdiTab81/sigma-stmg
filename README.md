# Sigma · Le quiz live des Terminale STMG

Quiz de maths en direct pour la Terminale STMG : les questions s'affichent au tableau, les élèves répondent sur leur téléphone (QR code + code de partie), en équipes sur ardoise, ou en solo.

## Contenu

- 12 chapitres : proportions et pourcentages, évolutions et taux, calcul numérique, équations et inéquations, lecture graphique, fonctions affines, dérivation, statistiques, probabilités, suites arithmétiques, reconnaître une suite, pourcentages et suites géométriques.
- 176 questions fixes et 31 modèles de questions générées (nouvelles valeurs à chaque partie).
- QCM, vrai ou faux, réponse à taper, remettre dans l'ordre ; courbes, tableaux croisés, arbres pondérés et feuilles de tableur dessinés.
- 16 avatars originaux, mode Boss, podium et bilan de séance (export CSV).

Tout tient dans un seul fichier `index.html`, sans installation ni compte.

## Mise en ligne (GitHub Pages)

1. Dans le dépôt : **Settings → Pages → Build and deployment**.
2. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
3. Après une minute, le jeu est en ligne à l'adresse `https://<compte>.github.io/<nom-du-depot>/`.

Le mode téléphones a besoin de cette adresse `https://` : il ne fonctionne pas en ouvrant le fichier depuis l'ordinateur. Les modes Équipes et Solo fonctionnent partout.
